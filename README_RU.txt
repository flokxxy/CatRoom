CAT COLLAGE — УРОК 1. ФОН КУХНИ
================================

Основа: учебный RG_V3 (OpenGL 3.3 + GLEW + GLFW + stb_image).
Это НЕ полная игра. На первом занятии мы выводим кухню на весь экран.

КАК ЗАПУСТИТЬ НА WINDOWS / VISUAL STUDIO
1. Распакуйте ZIP-архив в отдельную папку (не внутрь RG_V3).
2. Откройте CatRoom/CatRoom.sln в Visual Studio 2022 с поддержкой C++.
3. Выберите конфигурацию Debug | x64.
4. Запустите Local Windows Debugger (F5).
5. Появится окно «Cat Collage - lesson 1» с фоном кухни. Esc закрывает окно.

NuGet-пакеты GLEW и GLFW включены как в оригинальном RG_V3.
Если появляется ошибка об отсутствующем инструментарии v143,
проверьте установлен ли «Desktop development with C++» в Visual Studio Installer.

Если программа пишет «Cannot load res/kitchen_background.png»,
проверьте Project Properties > Debugging > Working Directory:
должна стоять папка CatRoom (значение $(ProjectDir)).
Файлы basic.vert и basic.frag также загружаются относительно этой папки.

ПОСЛЕ ЗАПУСКА
- Попробуйте заменить 1280 на 1000 в glfwCreateWindow: фон окажется обрезан,
  потому что glViewport остался прежним, а окно больше не совпадает по пропорциям.
  Верните 1280 после эксперимента.
- Найдите массив vertices[]: четыре вершины охватывают экран.
- Найдите glDrawArrays(): это команда, которая выводит прямоугольник с картинкой.
- Сравните Main.cpp с RG_V3: VAO/VBO почти такие же, но мы добавили UV-координаты.

ПРО ИЗОБРАЖЕНИЕ
Сейчас мы используем последнюю утвержденную кухню в размере 1280 x 720.
На ней уже изображены холодильник и картина. Перед интерактивной версией
их понадобится убрать с фона и отрисовывать как отдельные спрайты.

СТРУКТУРА КОДА
Main.cpp        — окно, VAO/VBO, загрузка картинки, цикл отрисовки
Util.cpp/.h     — функции из RG_V3 (создание шейдеров, загрузка PNG)
basic.vert      — определяет положение вершин и передает UV
basic.frag      — берет цвет каждого пикселя из PNG
res/kitchen_background.png — фон кухни
