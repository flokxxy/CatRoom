CATROOM — КРАТКИЙ ГАЙД ПО ЗАПУСКУ
================================

2D-игра на C++ и OpenGL 3.3 Core: разбудите кота, напоите молоком
и подружитесь с ним. Сборка и запуск проверены автором на Windows и macOS.
Репозиторий: https://github.com/flokxxy/CatRoom
Используйте версию проекта, содержащую CMakeLists.txt в корне.

ЗАПУСК ГОТОВОЙ СБОРКИ
--------------------
Windows: откройте папку build/bin/Release и запустите CatRoom.exe.
macOS: перейдите в build/bin/Release в терминале и выполните ./CatRoom.
Программа должна запускаться с рабочей папкой, содержащей res,
basic.vert и basic.frag. На Windows рядом также нужны glfw3.dll и glew32.dll.
CMake копирует эти файлы автоматически. Сохраняйте всю папку сборки целиком.

СБОРКА НА WINDOWS (x64)
----------------------
Нужны Visual Studio с компонентами разработки C++, MSVC v143 версии
14.44 или новее, Windows SDK и доступная в терминале команда cmake.
Минимум CMake — 3.21; для генератора Visual Studio 2026 нужен CMake 4.2+.
GLFW, GLEW и FreeType для Windows уже включены в проект.

В терминале из корня проекта выберите ОДНУ команду конфигурации:

Visual Studio 2022:
  cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -T v143

Visual Studio 2026:
  cmake -S . -B build -G "Visual Studio 18 2026" -A x64 -T v143

Затем соберите и запустите:
  cmake --build build --config Release
  cd build/bin/Release
  .\CatRoom.exe

Для Debug замените Release на Debug в команде сборки и пути программы.
Альтернатива: открыть CatRoom.sln, выбрать Release | x64, собрать и запустить.

СБОРКА НА macOS
---------------
Нужны Command Line Tools for Xcode, Homebrew и нативные библиотеки macOS.
Если инструменты Xcode ещё не установлены, выполните xcode-select --install.
Установка Homebrew: https://docs.brew.sh/Installation

В терминале из корня проекта:
  brew install cmake glfw glew freetype
  cmake -S . -B build -DCMAKE_BUILD_TYPE=Release "-DCMAKE_PREFIX_PATH=$(brew --prefix)"
  cmake --build build --config Release --parallel
  cd build/bin/Release
  ./CatRoom

КАК ИГРАТЬ
----------
1. Нажмите левой кнопкой мыши на лампу: свет включится, кот проснётся.
2. Нажмите на холодильник, чтобы открыть его.
3. Зажмите левую кнопку на пакете молока, перенесите пакет на область миски
   и отпустите кнопку. Затем отдельно нажмите на миску: начнётся наливание.
4. Дождитесь, пока кот подойдёт и выпьет молоко. После этого его можно гладить
   нажатием на тело. Пока кот сердитый, он отвечает шипением и укусом.
5. Доброго кота можно переносить: зажмите левую кнопку в области шеи.
   При отпускании подведите лапы к поверхности стола или столешницы.
6. Молоко можно вернуть: перетащите пакет в открытый холодильник и отпустите.
7. При выключении света кот засыпает; прогресс кормления и доброта сохраняются.
8. Мышка появляется справа из-за закрытого холодильника и прячется от наведения.

R — начать заново. Escape — выйти из игры.
Английские подсказки появляются во время игры.

ЕСЛИ НЕ НАХОДЯТСЯ ФАЙЛЫ
----------------------
Запускайте CMake-сборку из build/bin/Release (или build/bin/Debug).
Проверьте наличие res, basic.vert и basic.frag рядом с программой.
При запуске исходного решения CatRoom.sln рабочая папка — корень проекта.
Не переносите папку build между Windows и macOS: соберите проект на каждой ОС.
